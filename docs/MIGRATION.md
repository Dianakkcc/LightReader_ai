# 从旧调试签名迁移到正式发布签名

2.9.0 使用独立维护者发布证书 `CN=LightReader Release`。包名仍为 `com.lightreader`，但它与 2.8.0 / 2.8.1 的 Android Debug 证书不同。本轮按维护者选择只提供正式签名版，不提供旧证书过渡包。

**不要直接卸载旧版。先在旧版中完成以下操作。**

1. 打开「设置 → 数据 → 导出阅读数据」，将 JSON 存到应用私有目录之外，例如 Download，并确认文件存在且不是空文件。
2. 留好原始书籍文件。JSON 包含进度、书签和设置，**不包含书籍本体或自定义字体文件**；请另存需要的字体。
3. 记录书籍文件的位置。卸载会清除旧应用的书架数据库和私有缓存；不能依赖系统云备份作为此次换签名迁移手段。
4. 准备好上述文件后，用户自行卸载旧版并安装 2.9.0。新旧证书不同，系统拒绝直接覆盖是预期行为。
5. 在新版先重新导入原书，再到「设置 → 数据 → 导入阅读数据」选择 JSON。自定义字体需要重新导入、重新选择。
6. 抽查几本书的书签和阅读位置，确认恢复后再自行处理不需要的旧备份文件。

恢复时优先匹配原文件 URI；URI 变化时按唯一文件名匹配。同名书有多个候选时跳过，避免将进度写入错误书籍。遇到重复文件名，请先在新版只导入对应的一本，再恢复其数据。

备份不是完整设备镜像；当前格式不保证迁移所有界面偏好。JSON 含书名、位置、书签与文件 URI，应当作为个人数据保存。
