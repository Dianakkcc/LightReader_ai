# 许可说明

## 本项目的免费条件

维护者希望软件免费，不禁止企业免费使用，也不要求修改者公开自己的源码。项目中依法有权许可且受相应权利保护的代码、文档和图形采用根目录的 **LightReader 免费分发许可 1.0**。

| 行为 | 本项目有权许可部分的许可是否允许 |
| --- | --- |
| 自己使用、研究、修改 | 允许 |
| 公司内部免费使用 | 允许 |
| 免费发布原版或修改版 | 允许，保留许可和声明，修改版说明已修改 |
| 免费发布自己的闭源修改版 | 不强制公开自己的修改；第三方源码义务仍有效 |
| 给 APK 标价、收费下载或激活 | 禁止 |
| 付费解锁软件功能、按软件使用收费订阅 | 禁止 |
| 自愿捐赠、广告或独立支持服务收入 | 允许，完整软件不能以付款为获取/使用条件 |
| 重新分发单独取得的上游第三方库 | 遵守上游原许可，本项目不能取消其商业权利 |

这不是普遍禁止商业活动的 NC 许可，也没有“修改版必须开源”的 copyleft 条件。
MIT / Apache / GPL 都允许收费分发，无法直接表达本项目的免费条件。CC 官方不建议将 CC 许可用于软件。

本许可不是 OSI 标准开源许可，GitHub 可能显示 `Other`。项目描述应使用“源码公开 / 免费分发”，不宣传为 MIT、Apache、GPL 或 OSI 开源。

## 第三方例外

第三方代码与字体继续按上游许可授权：Apache-2.0、MIT、BSD-2-Clause、OFL-1.1 等。它们允许的商业利用权不会因本项目 LICENSE 而消失。
Rhino 的 MPL-2.0 仅用于测试，不进入正式 APK；若单独分发其二进制或修改文件，应遵守对应源码提供义务。依赖清单区分 release 与测试范围。

角色图片权利归第三方，分发授权尚未核实。来源说明和“如有侵权联系删除”不是授权文件，它们不适用项目原创许可。

## 分发时应携带的文件

源码携带 LICENSE、NOTICE、THIRD_PARTY_LICENSES.md、licenses/ 与素材说明。
APK 已打包原始许可文本、运行时坐标清单、版权/NOTICE 与素材声明，可从设置页离线查看；打包规则排除的重复 META-INF 许可由 assets 中的对应内容补充。
更新依赖版本后必须重新检查原始许可证/归档内素材，当前清单只适用于记录的版本。
