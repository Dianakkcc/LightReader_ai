# 隐私说明

适用版本：LightReader 2.8.1。

应用不申请 Android `INTERNET` 权限，没有账号系统、广告 SDK、统计 SDK 或自建上传服务器。应用自身不会主动上传书籍内容、阅读进度或使用遥测。

## 本地数据

- Room 数据库：书籍 URI/文件名、标题、作者、格式、封面路径、归属、阅读进度、书签和备注。
- DataStore：阅读与外观设置、书架列数等偏好。
- 应用私有文件：封面、导入/内置字体。
- 缓存：需要随机访问的原书副本、解析/图片/PDF 工作数据，可重建。

原书通常由系统文件提供程序管理。导入不会移动原书，但 EPUB、DOCX、漫画等格式和部分读取路径需要私有缓存副本。

## 数据可能离开设备的情况

1. Manifest 启用了 `allowBackup`。备份规则允许数据库、偏好和 DataStore 的 Android 系统云备份/设备迁移；实际执行取决于系统、设备厂商和用户备份设置。
2. 系统文件选择器允许用户选第三方文件提供程序，包括网盘。它们可能联网，受其自身政策控制。
3. 用户主动导出 JSON 或通过其他应用分享备份。JSON 包含书籍 URI、文件名、标题/作者、书签摘录与备注，不能当作无隐私的公开文件。
4. 开发日志可能包含文件名、资源路径、阅读位置和章节诊断信息。向 Issues 提交日志前请删除私人内容。

因此“不申请网络权限”不等于“系统与其他应用也绝不会传输这些数据”。如需完全本地使用，可选择本地文件提供程序并按系统设置管理备份。

## 控制与删除

用户可移除书架条目、删除书签、清理缓存、导出备份，或通过系统清除应用数据。卸载/清除数据会影响本地进度；备份提供程序中的副本应在对应系统/服务中管理。
