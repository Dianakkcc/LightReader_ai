# 使用指南

## 书架与导入

支持 Android 8.0（API 26）及以上。通过导入按钮选择文件；文件管理器支持相应 MIME 类型时，也可选择“用轻读打开”或分享给轻读。授权来自系统文件选择器，不需要整个磁盘的读取权限。

CBZ/ZIP 默认进入漫画书架，其余格式默认进入书籍书架。长按条目可更改归属；PDF/图片移到漫画架后按竖向连续流呈现。书架可切换列表/网格、排序和格式筛选。

## 每行数量

网格书架点“每行数量”：自动、2、3、4、5、6 列。书籍与漫画分别记忆，设置页也可调整。
自动按可用宽度决定列数；漫画未设置时默认 3 列。4～6 列使用紧凑间距和单行标题。列表布局不应用列数。

## 阅读

文字类文档可用连续滚动或分页，阅读设置调整字号、字体、行距、字间距、段距、缩进、对齐和边距。PDF/图片固定版式不会通过字号重排正文。

呼出阅读工具栏可进入目录、搜索、书签与设置；点目录会跳转到对应位置，漫画目录直接跳到对应页。文字章末不会仅因滚到末尾就自动换章，需要继续翻页或完成拉章手势。

阅读进度会保存。字体、系统字号和窗口尺寸改变后分页可能变化，字符位置与页码并非一一恒定对应。

## 字体和外观

内置 Noto Serif SC（OFL 1.1），首次启动复制到应用私有字体目录。可选择系统默认字体，或导入自己的 TTF/OTF 等受支持字体文件；文件能否加载依实际字体格式决定。

主界面配色与阅读纸色分别设置，可选择深浅色、主界面底色、经典/静奢设计语言。嘉然主题装饰图单独遵守第三方权利声明。

## 备份与换机

设置页的导出生成 JSON，包含书籍识别信息（URI、文件名、标题、作者）、书架归属、阅读位置、书签摘录/备注和设置。
**备份不包含原书或自定义字体文件**。跨设备字体路径不能直接沿用，应重新导入字体。

换机步骤：保存原书与字体 → 导出 JSON → 新设备安装 → 先导入相同书籍 → 恢复 JSON → 核对书签与进度。
恢复优先按 URI 匹配，其次按文件名匹配；不同书同名可能匹配错误。不要多次恢复同一备份，以免重复添加书签。

## 移除与删除

“从书架移除”删除条目及其阅读数据，保留设备上的原书。“删除本地文件”会尝试删除原文件，取决于文件提供程序的权限，操作前请自行确认。
缓存可重新生成，清理缓存不会重新获得已撤销的 URI 授权。卸载、清除应用数据可能丢失本地书架、进度与字体，请先导出。

## 常见问题

| 问题 | 检查方式 |
| --- | --- |
| 移动文件后打不开 | 从新位置重新导入，核对文件选择器授权 |
| EPUB 没有在线图片 | App 不加载网络资源，请使用包含本地资源的 EPUB |
| PDF 搜不到字 | 扫描件没有文字层，尚未提供 OCR |
| 漫画 ZIP 无目录 | 根目录图片是一章，文件夹图片按目录分章；先确认包内确实有受支持图片 |
| 设置滚动仍卡 | 记录机型、系统/WebView 版本、刷新率及卡顿的具体面板，按性能说明复现 |
| 安装提示签名不一致 | 需同一签名才能覆盖升级；保留旧应用数据，先导出备份，勿直接卸载 |
| unsigned APK 安装失败 | 这是未签名构建产物，先按构建文档签名 |
