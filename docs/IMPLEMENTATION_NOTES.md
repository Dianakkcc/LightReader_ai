# 当前实现说明

本文件记录 2.9.0 接手开发时应注意的实现约束；历史排查过程不作为当前设备实测结论。

## 文字引擎

文字格式统一输出章节内容，ChapterHtml 拼装 ReaderCss / ReaderScript，再交给 WebView。本地资源通过 reader.local 虚拟地址拦截，不需要联网。
JavascriptInterface 的桥接类型/方法必须可被 WebView 访问，并保留 R8 所需规则；桥接回调避免同名方法意外递归。
排版和章节加载是异步过程，TXT 后台章节索引更新后需同步相关章首/章末状态。修改 CSS 或字体后重新确认分页步长、字符偏移和边距。

## 面板与设置

ReaderScreen 使用窗口内面板。动画 State 在 graphicsLayer 读取，关闭动画完成后卸载并恢复阅读表面；平板侧栏路径也要验证。
设置列表采用 LazyColumn。滑杆本地跟随手指，松手提交；不要让每个移动事件都持久化或重排整章。
MainActivity 只观察应用外观字段；阅读参数、书架列数不应引发导航树的整体更新。

## 漫画与图片

漫画按目录/自然排序组成页流，目录跳转必须使 LazyColumn 实际滚到目标页，避免外部跳转与列表上报的位置互相覆盖。
图片头在后台读，ZIP 中的大图用流式解码。采样以目标宽度/高度决定；条漫仅适应宽度时不要使用 Int.MAX_VALUE 导致不降采样。
封面使用目标尺寸与缓存；新功能避免在组合阶段解压、读磁盘或解析字体。

## 存储与迁移

Room 保存书籍、进度和书签，DataStore 保存偏好。原文件 URI 与缓存副本是不同层次；缓存失效可重建，URI 授权失效必须重新取得。
书架归属和两架列数进入备份。跨设备备份匹配 URI/文件名，不携带原书，也不能自动恢复自定义字体文件。

## 发布与许可

release 默认未签名，通过环境变量使用维护者密钥。不要再把个人测试签名当成公共发布签名。
第三方许可原文在 licenses/，运行时副本在 assets/licenses；两份应一致。本项目许可不覆盖第三方图案和字体。
新增依赖或替换图片时同步更新清单、版权/NOTICE 与许可查看入口。
